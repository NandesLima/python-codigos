# 🐍 Python Masterclass: Repositório de Estudos

!!! abstract "Objetivo"
    Domine a linguagem Python através de uma trilha estruturada de estudos, partindo dos fundamentos até a manipulação avançada de dados e integração com APIs.

---

## 🎯 Visão Geral

Este repositório é o meu "caderno de estudos" oficial da linguagem Python. Aqui organizo e documento cada etapa do meu aprendizado, utilizando **Jupyter Notebooks** (`.ipynb`) para garantir que cada conceito seja testado e validado na prática.

---

## 🏗️ A Trilha de Estudo

O conteúdo está organizado em três grandes blocos:

=== "🌱 Fundamentos"
    - **Variáveis & Constantes:** Definição e boas práticas de nomenclatura.
    - **Tipos de Dados:** Inteiros, floats, strings, booleanos e conversões.
    - **Escopo:** Entendendo variáveis locais, globais e retornos de funções.
    - **Manipulação de Texto:** F-strings, slicing, métodos de string e estilização no terminal.
    - **Lógica de Programação:** Operadores aritméticos, relacionais e lógicos.

=== "🏗️ Estruturas de Dados & Controle"
    - **Condicionais:** `if`, `elif`, `else` e operadores ternários.
    - **Repetição:** Estruturas `for` e `while` para iteração eficiente.
    - **Coleções:** Uso profundo de Tuplas (imutáveis), Listas (dinâmicas), Conjuntos (sets) e Dicionários (chave-valor).
    - **Funções:** Criação de código modular, parâmetros e docstrings.
    - **Arquivos:** Leitura e escrita de arquivos de texto nativamente.
    - **Exceções:** Tratamento de erros com blocos `try-except-finally`.

=== "🤖 Módulos & Bibliotecas"
    - **Standard Lib:** Bibliotecas `OS`, `Random`, `CSV`, `JSON`, `Datetime` e `Time`.
    - **Automação:** Uso de `Shutil` para manipulação de arquivos no sistema operacional.
    - **APIs & Web:** Conexões HTTP com a biblioteca `Requests` e geolocalização com `Geopy`.
    - **Data Science Foundations:** Introdução à análise com `Pandas` e visualização com `Matplotlib`.
