## 🎯 Sobre o Projeto

Este é o meu "caderno de estudos" oficial. O material foi estruturado em módulos progressivos, sendo 100% desenvolvido de forma prática utilizando **Jupyter Notebooks (`.ipynb`)** para garantir que cada conceito possa ser testado imediatamente.

👉 **[Acessar o Site Oficial do Projeto](https://nandeslima.github.io/python-codigos)**

### 📚 Trilha de Estudos

1. **Fundamentos da Linguagem** (Variáveis, Escopo, Tipos de Dados, Strings).
2. **Estruturas de Controle** (Condicionais, Loops, Funções, Manipulação de Erros).
3. **Coleções de Dados** (Listas, Tuplas, Conjuntos e Dicionários).
4. **Módulos & Automação** (Manipulação de Arquivos e Pastas, JSON, CSV).
5. **Data Science Foundations** (Requisições Web, APIs, Pandas e Matplotlib).
